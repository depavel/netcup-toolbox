# Support

## Before opening an issue

1. Read the script's `--help` output.
2. Run the built-in self-test, for example `bash tools/netcup-ping.sh --self-test`.
3. Check the [README](../README.md) and [data documentation](../docs/DATA.md).
4. Search existing issues.

## Bug reports

Use the bug report template and include:

- the script name and release tag;
- the operating system and version;
- the exact command;
- the expected and actual output;
- relevant logs with credentials, customer numbers, IP addresses, and private
  hostnames removed.

## Security issues

Do not open a public issue. Follow [SECURITY.md](../SECURITY.md) and report the
problem privately.

## Scope

This repository contains community tooling. It is not operated by netcup GmbH.
Netcup account, billing, contract, and product availability questions must go to
the official netcup support channels.
